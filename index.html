导入题库

支持本工具 JSON 格式，以及 Codeforces / LeetCode 导出的通用 JSON、CSV。
想要几万道题的题库？ 在项目目录运行 node tools/build-banks.mjs， 脚本会从 Codeforces 官方 API 和 LeetCode 公开题库拉取题目标签，生成 data/bank-cf.js 与 data/bank-lc.js，刷新本页即可自动加载。
字段说明：answer 只能填知识点 id，完整 id 见 assets/patterns.js； 也支持直接写中文名（如 "哈希表"），导入时会自动映射。

AI 接入（可选）

接入任意 OpenAI 兼容接口后，可让 AI 出题、分级提示、点评你的解题思路。不填也能正常刷题。
本地代理模式下，请先用 node tools/serve.mjs 启动本地服务，并通过 http://127.0.0.1:8787 打开本页面。API Key 直接填在这里即可，只会发给你自己的电脑。
