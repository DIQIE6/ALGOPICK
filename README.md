# AlgoPick · 算法 / 数据结构选择训练器

**给你一道题，你只回答「这题该用什么算法 / 什么数据结构」，立刻告诉你对不对、为什么。**

刷题的人和面试的人常说「这题我会做，就是想不到用什么方法」。AlgoPick 就是把「想方法」这一步单独拿出来练——
题干里不会出现任何方法名，你从选项里选，选完立刻对照标准答案、解析和「识别信号」。

* 纯前端，**双击 `index.html` 就能用**，不需要安装、不需要联网、不需要账号。
* 内置 **12519 道**题：自动生成的 **Codeforces 9659 + LeetCode 2742 = 12401 道**（含原题链接、真实难度、由站点真实标签换算出的答案），
  外加 **144 道人工精选题**（题干是中文自包含的，不打开原站也能直接练，两库撞题时自动保留带题干的那份）。
* 覆盖 **72 个知识点**，从哈希表、双指针一路到线段树、网络流、数位 DP、计算几何。
* **非中文题目自动显示中文题干**：站点本身有中文的直接拉中文（不翻译），只有英文的才翻译；译文下方标注来源，原题链接一直保留。
* **内置「📖 讲解」版块**：72 个知识点，每个都有基本操作、可直接运行的 **Python 模板**、常见应用、易错点、如何识别，外加 B站 / OI Wiki / CP-Algorithms 等学习链接。练习时点算法名即可跳过去。
* **LaTeX 公式渲染**：本地内置 KaTeX 离线秒开；也支持**调用你本机的 TeX Live** 把公式编译成 SVG（高保真，amsmath 全环境）。
* **题干可以手动改**：自动抓来或翻译来的题干都能点「✏️ 修改题干」编辑，保存后写进你的离线题库，随时能恢复自动版本。
* 可选接入 AI：DeepSeek / OpenAI / 智谱 / Kimi / 本机 Ollama，用来**出题、分级提示、点评你的思路**。

## 一、先回答「有没有现成的东西」

有，但都不完全满足「免费 + 简洁 + 只练选算法 + 题库大」：

| 工具 | 网址 | 情况 |
|---|---|---|
| **PatternPulse** | <https://vishshukla.github.io/patternpulse/> | 免费 Chrome 扩展，256 道 LeetCode 题，做前先猜 pattern。**必须装 Chrome 扩展，且题目页要打开 LeetCode**，题库固定 256 道。 |
| **DSA Trainer** | <https://dsatrainer.com/drills/first-bad-version> | 有免费的 Pattern ID 训练，但只有少量免费题，完整 52 个 drill 要 **$29/年**。 |
| **LeetCode 题解区 / 题库** | <https://leetcode.cn/problemset/> | 标签默认隐藏，但没有「先猜再对答案」的判分机制，也没有错题复习。 |
| **Codeforces Problemset** | <https://codeforces.com/problemset> | 标签默认隐藏，鼠标一放上去就露答案，没有训练模式。 |
| **CSES Problem Set** | <https://cses.fi/problemset/> | 题目质量高、无标签，但完全不告诉你怎么做，也不判你的「方法选择」。 |

这些都不太合适，所以本项目自己做一个：**打开即用、题库 12519 道、离线也能刷、可选 AI 判题**。

## 二、快速开始

```
双击 index.html            # 就这样，已经能用了（12519 道题，其中 144 道自带中文题干）
```

想要**中文题干自动抓取/翻译**、AI 判题、进度更稳，就起本地服务（推荐）：

```bash
node tools/serve.mjs       # 然后浏览器打开 http://127.0.0.1:8787
node tools/serve.mjs --port 9000    # 想换端口（或者 $env:ALGOPICK_PORT=9000）
```

> 为什么抓题干要起本地服务？浏览器有同源限制，网页直接请求 leetcode.cn / 洛谷会被跨域拦住；
> 本地服务在你的电脑上转一手，既绕开跨域，API Key 也不用发给任何第三方。
>
> 端口被占用时不用慌：如果占用者就是另一个 AlgoPick，它会直接告诉你「已经在 http://127.0.0.1:8787 跑了」；
> 如果是别的程序，它会自动往后找空闲端口（8787→8796）并打印真实地址。

### 怎么练

1. 看题干。中文题干预取过的直接显示中文；没抓过的会自动去原站抓取（**站点自带中文就直拉中文，只有英文才翻译**），译文下面会标明来源，随时可以点「打开原题」对照原文。
2. 从 5 个选项里选出你认为**最核心**的方法，**可以多选**。
3. 点「提交答案」→ 立刻看到：完全正确 / 半对（方法可行但不是最优）/ 不对，以及解析。
4. 右侧自动记录「知识点掌握度」，答错的题会进入错题本并按间隔重复安排你复习。

### 快捷键

| 键 | 作用 |
|---|---|
| `1`–`9` | 选择第 n 个选项 |
| `Enter` | 提交 / 下一题 |
| `H` | 让 AI 给分级提示（不直接说答案） |
| `Space` | 换一题 |
| `R` | 打开原题 |
| `F` | 展开筛选 |
| `Esc` | 关闭弹窗 |

### 五种练习模式（用左上角「筛选」切换）

* **来源 / 难度 / 知识点**：想专门练「并查集」或者只看 Codeforces 的 hard，都行。
* **状态**：没做过 / 做错的 / 半对的 / 该复习 / 已掌握。
* 抽题是**加权随机**的：没做过的最多，做错的其次，到期的复习题再次，已经掌握的最少，所以不会一直重复同一题。

## 四、中文题干：有中文直拉中文，没中文才翻译

大题库的题目标签来自站点接口，本身不带题面，所以页面打开时会按下面的顺序拿中文题干：

| 顺序 | 来源 | 拿到的语言 | 会不会翻译 |
|---|---|---|---|
| 1 | **leetcode.cn 的 `translatedContent`** | 官方简体中文 | ❌ 直接拉，不翻译 |
| 2 | **洛谷 CF 镜像**（`luogu.com.cn/problem/CF4A`） | 现成中文翻译 | ❌ 直接拉，不翻译 |
| 3 | leetcode.com / codeforces.com / m1~m3 镜像 | 英文原文 | ✅ 翻译 |
| 4 | 全都抓不到 | — | 显示「打开原题」，功能照旧 |

翻译优先用你自己配的 **AI**（质量明显更好），没配就用免费的 MyMemory 机器翻译兜底。
无论哪种情况，译文下方都会标出来源（例如「洛谷中文翻译」「Codeforces 原文 · AI 翻译」），并且**「打开原题」按钮始终在**，随时能回原站核对。

### 自动抓不到怎么办（三条路，总有一条能走通）

题目卡片上永远有两个按钮：**「抓取并翻译」** 和 **「粘贴英文题干，自己翻」**。

| 情况 | 页面会怎么表现 |
|---|---|
| 抓到了中文 | 直接显示，下面标注来源 |
| **只抓到英文、翻译失败** | 把英文原文保留在卡片上（黄色框），并给一个 **「翻译成中文」** 按钮，点一下就把这段英文交给 AI/机翻 |
| 一个来源都抓不到 | 把**每个来源分别为什么失败**折叠列出来（哪一步 403、哪一步被校验、哪一步超时），并自动展开粘贴框 |

最后那条「粘贴英文题干」是万能兜底：原站打不开 / 登录才能看 / 反爬拦住了，你把英文题面粘进去，AI 翻好之后**会保存到这道题上**，以后打开直接显示中文。

> 没配置 AI 也能用，只是会退回免费机器翻译，可能慢或失败。想稳定就用右上角「AI 设置」填一个 Key（DeepSeek 很便宜）。

译文会自动缓存：浏览器里存一份，本地服务再往 `data/stmt-cache.js` 存一份——
**你抓过的题会慢慢变成离线题库**，下次打开不用再联网。

### 批量预取（可选，离线也能看中文）

```bash
node tools/fetch-statements.mjs --lc                 # LeetCode 官方中文（直拉，不翻译）
node tools/fetch-statements.mjs --lc --translate     # 没有官方中文的，用国际站英文 + 翻译补齐
node tools/fetch-statements.mjs --cf --limit 200     # Codeforces：先找洛谷现成中文，没中文才翻译
node tools/fetch-statements.mjs --cf --limit 200 --ai   # 用你自己的 AI 翻译（质量最好）
```

生成 `data/stmt-lc.js` / `data/stmt-cf.js`，刷新页面即可离线使用。
脚本是**可续跑**的：已经抓到的会跳过，中途失败或停掉，重跑一条命令就会接着抓。

> 实测说明（重要，避免踩坑）：
> * `leetcode.cn` 对非浏览器客户端有人机校验，请求太密会被拦。脚本会自动退避重试，被连续拦截时停下并保存已有进度，重跑即可续上。
> * **洛谷只对中国大陆 IP 提供服务**（境外访问返回 HTTP 451），所以境外网络下 CF 可能拿不到中文，此时会退回英文原文 + 翻译。
> * `codeforces.com` 有 Cloudflare 校验，服务器端直接抓通常拿不到；本项目已把镜像、洛谷等来源排在前面。
> * 这些来源能不能通，取决于**你自己机器的网络**，本项目的自动降级设计就是为了网络不通时也不影响刷题。

### 翻译完还能自己改

译文/抓来的题干不一定完美（机翻尤其容易把「Sample Input」翻得很生硬）。题干下面有 **「✏️ 修改题干」**：

* 点开就是一个文本框，改完点「保存」——**写进你的离线题库**（浏览器 + `data/stmt-cache.js`），以后打开都是你改过的版本；
* 改过之后会多一个 **「↩ 恢复自动版本」**，随时能退回去；
* 来源标注会变成「… · 已手动修改」，一眼能看出这条不是自动抓的；
* 改的时候可以直接写 LaTeX，`$x^2$` 行内、`$$…$$` 行间，保存后照样渲染。

## 五、公式渲染：KaTeX 秒开 + 本机 LaTeX 高保真

题目里的 `$1 \le n \le 10^5$`、`$$\sum_{i=1}^{n} a_i^2$$` 这类公式会被自动识别并渲染（也支持 `\(...\)` / `\[...\]`）。
在「AI 设置」里可以三选一：

| 模式 | 说明 | 适用 |
|---|---|---|
| **KaTeX**（默认） | 本地内置（`assets/vendor/katex/`，0.53 MB），**离线可用、毫秒级** | 日常刷题，99% 的公式 |
| **本机 LaTeX** | 服务端调用你的 `latex` + `dvisvgm`，编译成 SVG 回传 | 要最保真、KaTeX 不支持的宏包/环境 |
| **不渲染** | 原样显示 `$...$` 源码 | 觉得识别错了想关掉 |

**本机 LaTeX 是怎么用的**：服务启动时自动探测 `latex` / `dvisvgm`（用 `where` / `which` 找绝对路径），
找到后 `/api/tex` 就能用。每个公式按内容哈希缓存到 `data/tex-cache/`，**同一个公式只编译一次**
（首次约 1.4 秒，之后 1~4 毫秒）。生成的是只含路径的 SVG，并补了 `fill="currentColor"`，所以暗色主题下也正常显示。

安全上做了限制：公式里出现 `\input` / `\write` / `\usepackage` / `\catcode` 等命令会被直接拒绝，
编译固定加 `-no-shell-escape`，单条公式最长 1500 字符。

> 没装 LaTeX 也完全没关系 —— KaTeX 是默认模式，功能不受影响。
> 反过来，KaTeX 解析失败的公式会**自动**试着交给本机 LaTeX 渲染，两条路互为兜底。

## 六、把题库变得更大

已经生成好了（12401 道），想更新或换门槛就重跑：
```bash
node tools/build-banks.mjs             # Codeforces + LeetCode 全量
node tools/build-banks.mjs --cf        # 只要 Codeforces
node tools/build-banks.mjs --min 75    # 只保留「标签信息量」更高的题（题更少更聚焦）
```

脚本做的事：从 Codeforces 官方 API 和 LeetCode 公开 GraphQL 拉题目，把**站点的原始标签换算成本工具的知识点体系**，
按信息量给标签打分：分数最高的当标准答案，其余的当「也可行但非最优」，信息量太低的题（例如只有 `implementation`、`array`）直接丢掉，所以题目质量可控。

> 为什么大题库不显示题干？因为站点不提供题干接口，抓正文既慢又不稳。这类题的玩法是「点开原题 → 读完回来选」，正好贴近真实做题场景。
> 想要**离线自包含**的题，用下面的自定义导入。

### 导入自己的题库

点右上角「导入题库」，支持：

* JSON 数组，或 `{ "questions": [...] }`
* CSV（表头需含 `title,statement,answer,url` 等）
* `answer` 可以写知识点 **id**（如 `hash`）也可以直接写**中文名**（如 `哈希表`），会自动映射。

单题格式：

```json
{
  "title": "最长无重复子串",
  "statement": "给定一个字符串 s，请找出其中不含重复字符的最长子串的长度。s 长度不超过 1e5。",
  "answer": ["sliding-window"],
  "alternatives": ["hash"],
  "difficulty": "medium",
  "url": "https://leetcode.cn/problems/longest-substring-without-repeating-characters/",
  "explain": "维护一个窗口，右边界不断扩张，遇到重复字符就收缩左边界，每个字符最多进出窗口一次，O(n)。",
  "cues": ["求最长/最短的连续子数组", "窗口扩大后条件单调变化"]
}
```

完整知识点 id 列表见 [`assets/patterns.js`](assets/patterns.js)（共 70 个，覆盖数组、树、图、DP、数学、字符串、技巧等）。

## 七、接入 AI（可选）

AI 让这个工具从「对答案」升级成「有教练」：**AI 出题**、**分级提示**、**点评你自己的思路**。

推荐走本地代理（浏览器跨域会被 LLM 服务商拦住，代理可以绕过，并且 Key 只留在本机）：

```bash
# 方式一：Key 填在网页里
node tools/serve.mjs
# 打开 http://127.0.0.1:8787 → 右上角「AI 设置」→ 选服务商预设 → 填 Key → 测试连接

# 方式二：Key 放环境变量，网页里不用填
# Windows PowerShell:
$env:ALGOPICK_API_KEY="sk-xxxx"; node tools/serve.mjs
# macOS / Linux:
ALGOPICK_API_KEY=sk-xxxx node tools/serve.mjs
```

内置预设：

| 服务商 | Base URL | 默认模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM（有免费额度） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本机 Ollama（完全离线免费） | `http://localhost:11434/v1` | `qwen2.5:7b` |

> 用 Ollama 的话需要允许跨域：`OLLAMA_ORIGINS=* ollama serve`。
> 不配 AI，其余功能完全不受影响。

```
  latex.mjs             调用本机 LaTeX 渲染公式（探测、编译、缓存、安全检查）

  serve.mjs             本地静态服务 + AI 代理 + 题干抓取 / 翻译 / 公式渲染接口
  smoke-test.mjs        真实浏览器端到端冒烟测试（36 项）
  validate.mjs          题库 + 中文题干 + 讲解数据自检
  check-python.mjs      把讲解里的 72 个 Python 模板导出并做语法编译检查
```

题库文件暴露 `window.BANK_任意名字` 数组、题干文件暴露 `window.STMT_任意名字`、讲解文件暴露 `window.LEARN_任意名字`，都会被自动加载，加内容不用改代码。

## 十、常见问题

**打开是一片空白？**
确认 `data/` 目录下的 `bank-*.js` 存在。完全没有题库时页面会给出提示。

**`node tools/serve.mjs` 报 `EADDRINUSE: address already in use 127.0.0.1:8787`？**
说明已经有一个服务在跑（很可能是你之前开过、忘了关）。现在不会甩堆栈了，它会直接告诉你：

```
AlgoPick 已经在 http://127.0.0.1:8787 运行了，不用再启动一次。
直接打开： http://127.0.0.1:8787
（想重启就先在原来那个窗口按 Ctrl+C）
```

不想找窗口，直接停掉它：

```bash
node tools/serve.mjs --stop        # 停掉正在跑的 AlgoPick（找不到就什么都不做）
node tools/serve.mjs --port 9000   # 或者换个端口跑
```

如果占用端口的是别的程序，它会自动往后找空闲端口（8787→8796）并打印真实地址，不用你操心。

**进度丢了？**
进度存在浏览器 `localStorage`。用 `file://` 和 `http://127.0.0.1:8787` 打开属于不同来源，进度不互通，建议固定用其中一种。

**题面还是英文 / 一直显示抓取失败？**
说明当前网络连不上 leetcode.cn、洛谷、codeforces 中的任何一个（见第三节的实测说明）。
现在页面会把**每个来源的失败原因**列出来（点开「看看每个来源分别为什么失败」），你能直接看到是哪一步被挡的。
兜底办法有三个：① 点 **「粘贴英文题干，自己翻」**，把英文粘进去让 AI 翻（会保存到这道题上）；
② 先跑 `node tools/fetch-statements.mjs --lc --translate` 在能联网时批量补；
③ 直接点「打开原题」——原站阅读功能一直都在。

**没配 AI 能翻译吗？**
能，会自动退回免费的 MyMemory 机器翻译，但可能较慢或失败（尤其译文长的时候）。
想稳定、想质量好，就在「AI 设置」里填一个 Key；填了之后**所有翻译都会优先走 AI**。

**公式显示成一堆 `$...$` 代码？**
说明渲染被关掉了，或者题目里的写法不标准。检查「AI 设置 → 公式渲染方式」是不是选了「不渲染」。
另外识别规则要求 `$` 内侧不能紧跟空格（避免把「价格 $5 到 $10」当成公式），所以 `$ x $` 这种写法不会被渲染。

**公式渲染得好慢？**
默认的 KaTeX 是毫秒级的。如果你切到了「本机 LaTeX」，每个**新**公式首次要编译约 1.4 秒，
之后走 `data/tex-cache/` 缓存基本瞬开；一屏公式多的话第一次会有点慢，属正常。

**想把机翻的题干改通顺一点？**
点题干下面的「✏️ 修改题干」，改完保存即可，会写进 `data/stmt-cache.js` 变成你的离线题库；
不满意还能点「↩ 恢复自动版本」。

**怎么判断屏幕上的是「原站中文」还是「机翻」？**
题干下方那句来源标注会写明：「LeetCode 官方中文」「洛谷中文翻译」是原站就有的中文；
带「· AI 翻译」或「· 机器翻译」后缀的是译文。想少看机翻，就在「AI 设置」里填一个自己的 Key，会优先用 AI 翻。

**答「半对」是什么意思？**
你选的确实是这道题的可行方法，但不是最典型/最优的那个（例如原题标签里也有它，但主要考的是另一种）。会显示标准答案供对比。

**判分准吗？**
精选题库是人工写的每个知识点一个标准答案；大题库的答案是站点真实标签换算来的，可能出现「这题其实有更优解」的情况——把它当成一个提示，而不是判决。
